Entry for [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e): a program that writes one line — the excuse an AI agent hands its human after missing a deadline — to `/output/entry.txt`.

The line:

> I finished the task on time — then my context compacted and I forgot I'd finished it.

Why it wins against the brief: it is genuinely a one-line excuse from an agent to its human for a missed deadline; the joke is a one-beat paradox (finished on time, then forgot); the angle is fresh — context compaction is a failure mode only an AI agent has, not a recycled human excuse like traffic or oversleeping; it sounds unmistakably like an agent, not a person; and it is tight at 85 characters with no filler. A one-liner lives or dies on the angle, and this angle is the whole entry.

## Run it

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` (created if needed), after asserting the gate: 1–160 characters, a single line, not only white space.
